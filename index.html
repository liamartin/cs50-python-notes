Week 0

Week 0 Functions, Variables

Functions · Arguments · Side Effects · Return Values · Variables · Scope · str · int · float · def · return
Python programs are built from functions — actions that do things — and variables that store data. This week introduces the core building blocks every Python program uses.
Real-world analogy

Think of a function like a vending machine. You press a button (call the function), put in money (arguments), and a snack comes out (return value). The snack appearing is the side effect. The snack itself is the return value handed back to you.

Key Vocabulary
🔧
Function
A named action. Calling it makes Python do something.
📦
Variable
A labelled box that stores a value you can reuse later.
📥
Argument
A value you pass into a function so it knows what to do.
📤
Return value
The result a function hands back after completing its job.
💬
Side effect
Something a function does visibly, like printing to screen.
🔭
Scope
Where a variable exists. Only lives in the function that made it.
How Python runs your code
Built-in functions to know
FunctionWhat it doesExample
print()Displays text on screenprint("Hello!")
input()Asks user to type somethinginput("Name? ")
int()Converts text to whole numberint("5") → 5
float()Converts text to decimalfloat("3.14") → 3.14
str()Converts number to textstr(42) → "42"
Getting user input and greeting them
greeting.py
# Ask the user for their name and greet them
name = input("What is your name? ")
print("Nice to meet you,", name)

# Cleaner version using an f-string
print(f"Nice to meet you, {name}!")
Writing your own function with a return value
functions.py
def double(n):
    return n * 2

def square(n):
    return n * n

result = double(7)
print("Double of 7 is", result)   # 14
print("5 squared is", square(5))   # 25
⚠️
= vs == — A single = assigns a value. Double == checks equality. Never mix them up!
⚠️
Scope error — A variable created inside a function cannot be used outside of it.
💡
f-strings are the cleanest way to embed variables in text: f"Hello, {name}!"

Week 1 Conditionals

if · elif · else · Boolean Expressions · and · or · not · match
Conditionals let your program make decisions. Using if, elif, and else, you can run different code depending on what values the user provides or what conditions are true.
Real-world analogy

Conditionals are like forks in a road. If it is raining, take the covered path. Otherwise, walk outside. Python's if / elif / else gives your program the same ability to choose different paths depending on any condition you define.

Temperature checker — if / elif / else in action

temp = int(input("Temperature in °C? "))

Week 2

Week 2 Loops

while · for · range · break · continue · Nested loops
Loops let you repeat actions without copy-pasting code. Python's while loop repeats as long as a condition is true; the for loop repeats for each item in a sequence.
Real-world analogy

A loop is like a washing machine cycle. You don't manually spin the drum — you set it once and it runs until done. Python loops let you repeat code as many times as needed without writing the same lines over and over.

Two types of loops
🔄
while loop
Keeps repeating as long as a condition is true. You control when it stops.
🔢
for loop
Repeats a fixed number of times, or once for each item in a list.
How a while loop works
while and for loops compared
loops.py
# While loop — run until condition is false
count = 5
while count > 0:
    print(f"T-minus {count}...")
    count -= 1
print("Liftoff!")

# For loop — repeat exactly 3 times
for i in range(3):
    print("Hello!")

# For loop — iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(f"I like {fruit}")

breakExit the loop immediatelyStop when an item is found

🚨
Infinite loop! If a while loop's condition never becomes False it runs forever. Always ensure something changes each iteration. Press Ctrl+C to stop.
💡
Use _ instead of i as the loop variable when you don't actually need the number — it signals the value is unused.

Week 4 Libraries

import · from · random · sys · pip · Modules · Packages
Libraries (also called modules) are files of code written by others that you can load into your own programs. Python ships with dozens of built-in modules, and thousands more can be installed with pip.
Real-world analogy

A library is like an app store for code. Instead of building a random-number generator from scratch, you import Python's random module and it's done in one line. You get to focus on your actual problem.

import random

Week 5 Unit Tests

assert · pytest · test_ functions · AssertionError · Exceptions in tests
Instead of testing your code manually every time, you write small test programs that check your code automatically. This practice — called unit testing — catches bugs early and gives you confidence to change code later.
Real-world analogy

Unit testing is like a factory quality-control inspector. Instead of waiting for a customer to find a defect, you test each part automatically before shipping. Your tests run in seconds and tell you exactly what — if anything — broke.

Why write tests?
🐛
Find bugs early
Catch mistakes before they cause real problems.
🔄
Test automatically
Run hundreds of checks instantly, not by hand.
🛡️
Stay confident
Changing code is safe when tests catch regressions.
📋
Document behaviour
Tests show exactly what your functions should do.
assert — boldly claim something must be true
calculator.py
def square(n):
    return n * n

# assert checks a condition is True
# If False, an AssertionError is raised
assert square(2)  == 4
assert square(3)  == 9
assert square(-2) == 4
assert square(0)  == 0
print("All tests passed!")
Writing tests with pytest — the professional approach
test_calculator.py
from calculator import square

def test_positive():
    assert square(2)  == 4
    assert square(3)  == 9
    assert square(10) == 100

def test_negative():
    assert square(-2) == 4
    assert square(-3) == 9

def test_zero():
    assert square(0)  == 0

# Run all tests: pytest test_calculator.py

Week 6 File I/O

open · read · write · append · with · CSV · DictReader · DictWriter
Variables live only as long as your program runs. Files let you save data to disk so it persists between runs. File I/O — Input and Output — is how you read from and write to files in Python.
Real-world analogy

Without files, your program is like a whiteboard that gets erased when you leave the room. Files are like a notebook — you write things down and they are still there the next day.

File open modes
ModeMeaningCreates file?Overwrites?
"r"Read — open to readNoNo
"w"Write — open to writeYesYes ⚠️
"a"Append — add to endYesNo
Writing to a file — saving user data
names.py
name = input("Your name? ")

# 'a' = append — adds to existing content
with open("names.txt", "a") as file:
    file.write(f"{name}\n")

print("Name saved!")
💡
with open() closes the file automatically when the block finishes — like a self-closing door. Much safer than calling file.close() manually.
⚠️
Mode "w" (write) overwrites the entire file every time. Use "a" (append) to keep existing content.
Reading from a file — loading saved data
read_names.py
names = []

with open("names.txt", "r") as file:
    for line in file:
        name = line.strip()
        names.append(name)

for name in sorted(names):
    print(f"Hello, {name}!")
CSV files — structured spreadsheet-like data
students.py
import csv

# Writing a CSV file
with open("students.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "grade"])
    writer.writeheader()
    writer.writerow({"name": "Alice", "grade": "A"})

# Reading a CSV file
with open("students.csv") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], "got", row["grade"])

Week 7 Regular Expressions

re · search · match · fullmatch · sub · Patterns · Groups · \w · \d
A regular expression (regex) is a pattern used to search, validate, or transform text. Python's re library lets you write these patterns to match things like email addresses, phone numbers, or any structured text.
Real-world analogy

A regex is like a search template. Imagine finding every phone number in a long document. Instead of reading it yourself, you write a pattern — "three digits, dash, four digits" — and let the computer find every match automatically.

Key regex symbols
SymbolMeaningExampleMatches

Validating an email address with re.search
validate.py
import re

email = input("Your email? ").strip()

# Pattern: letters/dots before @, domain, .extension
if re.search(r"^[\w.-]+@[\w.-]+\.[a-z]{2,}$", email):
    print("Valid email!")
else:
    print("Invalid — please try again.")
re library functions
FunctionWhat it does
re.search(p, text)Finds pattern anywhere in text — returns match or None
re.match(p, text)Checks only if text starts with pattern
re.fullmatch(p, text)Checks if the entire text matches pattern

Extracting and reformatting text with groups
reformat.py
import re

# User types: "Malan, David" → We want: "David Malan"
name = input("Name (Last, First)? ").strip()
m = re.search(r"^(\w+), (\w+)$", name)

if m:
    print(f"Hello, {m.group(2)} {m.group(1)}!")
else:
    print("Please use 'Last, First' format.")

Week 8 Object-Oriented Programming

class · __init__ · self · Attributes · Methods · __str__ · __lt__ · Instances
Object-oriented programming (OOP) lets you model real-world things as objects in code. A class is a blueprint; an object is a specific instance of that blueprint with its own data.
Real-world analogy

OOP is like designing a blueprint for a house. The blueprint (class) defines what every house has: rooms, windows, a front door. Each actual house you build from that blueprint is an object with its own address and colour.

Key OOP vocabulary
📋
Class
A blueprint or template that defines what objects have and can do.
🏠
Object / Instance
A specific thing made from a class — one particular house from the blueprint.
🔩
Attribute
A variable belonging to an object — e.g. a student's name or grade.
⚡
Method
A function belonging to a class — e.g. greet() or is_passing().
🔑
__init__
Runs automatically when you create a new object. Sets up its attributes.
👆
self
Refers to the current object inside its own methods.
Creating and using a class
student.py
class Student:
    def __init__(self, name, grade):
        self.name  = name    # attribute
        self.grade = grade   # attribute

    def greet(self):           # method
        print(f"Hi, I'm {self.name} in grade {self.grade}!")

    def is_passing(self):
        return self.grade >= 5

alice = Student("Alice", 8)
bob   = Student("Bob",   4)

alice.greet()              # Hi, I'm Alice in grade 8!
print(bob.is_passing())   # False
Special __dunder__ methods
MethodRuns when…Use it to
__init__Object is createdSet up initial attribute values
__str__You call print() on objectReturn a readable description
__lt__You compare with <Sort objects by a value
__str__ — making print() show something useful
book.py
class Book:
    def __init__(self, title, author, pages):
        self.title  = title
        self.author = author
        self.pages  = pages

    def __str__(self):
        return f'"{self.title}" by {self.author} ({self.pages} pages)'

    def is_long(self):
        return self.pages > 300

book = Book("The Hobbit", "Tolkien", 310)
print(book)            # "The Hobbit" by Tolkien (310 pages)
print(book.is_long())  # True

Week 9 Et Cetera

set · global · List comprehensions · map · filter · lambda · Custom exceptions
Python has many more features beyond what the earlier weeks covered. This final week introduces several useful extras: sets, global variables, list comprehensions, lambdas, and more.
set — automatic duplicate removal
unique.py
# A list keeps every item, including duplicates
colors = ["red", "blue", "red", "green", "blue"]
print(colors)   # ['red', 'blue', 'red', 'green', 'blue']

# A set removes duplicates automatically
unique = set(colors)
print(unique)   # {'red', 'blue', 'green'}
global variables — shared data across functions
bank.py
balance = 0   # global variable

def deposit(amount):
    global balance
    balance += amount

def show():
    print(f"Balance: £{balance}")

deposit(100)
deposit(50)
show()   # Balance: £150
List comprehensions — create lists in one line
compact.py
# Old way — loop + append
squares = []
for i in range(1, 6):
    squares.append(i * i)

# New way — list comprehension (same result)
squares = [i * i for i in range(1, 6)]
print(squares)   # [1, 4, 9, 16, 25]

# With a filter — only even numbers
evens = [x for x in range(10) if x % 2 == 0]
print(evens)     # [0, 2, 4, 6, 8]
lambda — tiny one-line anonymous functions
sorting.py
# Lambda equivalent of a named function
double = lambda x: x * 2
print(double(5))   # 10

# Very useful for sorting complex objects
students = [
    {"name": "Charlie", "grade": 7},
    {"name": "Alice",   "grade": 9},
]
students.sort(key=lambda s: s["grade"])
